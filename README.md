# Food App Funnel & A/A/B Testing 🍕📊
> Análise do comportamento do usuário em um aplicativo de delivery, mapeando o funil de conversão e avaliando testes estatísticos A/A/B para tomada de decisão baseada em dados.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Manipulação e Análise de Dados:** Pandas, NumPy
- **Estatística & Testes de Hipóteses:** SciPy (Testes Z para proporções, Testes A/A/B)
- **Visualização de Dados:** Matplotlib, Seaborn
- **Controle de Versão:** Git e GitHub

## 🚀 Funcionalidades & Pipeline do Projeto
- **Análise Exploratória de Dados (EDA):** Verificação de logs de eventos, limpeza de dados nulos ou duplicados e rastreio da jornada do usuário.
- **Mapeamento do Funil de Conversão:** Identificação das etapas críticas (Visualização da Tela Principal -> Tela de Ofertas -> Carrinho -> Tela de Pagamento/Sucesso) para detectar gargalos de abandono.
- **Testes Estatísticos A/A/B:** Avaliação do impacto de uma mudança no design de fontes da interface, comparando dois grupos de controle (A/A) contra o grupo de teste (B) para garantir a confiabilidade estatística e mitigar erros do Tipo I e II.
